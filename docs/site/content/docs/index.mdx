This is the documentation site for `python-template`, a template for yo61
Python projects. It ships a `pythontemplate` package, a `cyclopts`-based CLI,
and the tooling — linting, type checking, tests, CI — to build on top of.

- [Tutorials](/tutorials) — learning-oriented walkthroughs. Start here.
- [How-to guides](/how-to) — task-oriented recipes for a specific goal.
- [Reference](/reference) — look-up material: commands, flags, configuration.
- [Explanation](/explanation) — background and design reasoning.
- [Contributing](/contributing) — how to work on the project itself.
